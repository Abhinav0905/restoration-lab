## Description

A fault has interrupted 700 customers and a community hospital. Restoration Lab lets a trainee operate a synthetic one-line feeder while a deterministic safety gate checks every proposed action before the network changes.

Training model only. All data is synthetic. This project is not for operational switching, protection studies or control-system use.
